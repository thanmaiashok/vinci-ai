# Vinci AI

**A local RAG-powered reasoning assistant inspired by Leonardo da Vinci.**  
Ask questions about art, anatomy, mechanics, fluid dynamics, optics, and geometry — answered using Leonardo's actual notebook texts, retrieved via FAISS vector search and a local LLM.

---

## Features

- **RAG pipeline** — FAISS vector index over Leonardo's labeled notebook entries
- **Local LLM** — runs fully offline via [Ollama](https://ollama.com) (no API keys, no cloud)
- **Smart routing** — small talk bypasses RAG; topic-relevant questions trigger retrieval
- **Responsive UI** — plain HTML/CSS/JS chat interface, works on all screen sizes
- **Fast setup** — single `setup.bat` installs everything

## Quick Start

```bat
:: 1. Clone the repo
git clone https://github.com/thanmaiashok/vinci-ai.git
cd vinci-ai

:: 2. Run setup (installs deps, pulls model, builds index)
setup.bat

:: 3. Start the app
start_vinci_ai.bat
```

The chat UI will open in your browser. The FastAPI backend runs at `http://localhost:8000`.

## How It Works

```
User question
     │
     ▼
 is_smalltalk()?  ──Yes──▶  Ollama (no RAG)
     │
     No
     │
     ▼
 is_notebook_question()?  ──No──▶  Ollama (general answer)
     │
     Yes
     │
     ▼
 FAISS retrieval (top-5 chunks)
     │
     ▼
 Build structured prompt with context
     │
     ▼
 Ollama LLM generates response
     │
     ▼
 Answer returned to chat UI
```

## Rebuilding the Index

If you update `data/vinci_labeled.jsonl`, rebuild the FAISS index:

```bat
venv\Scripts\activate
python -m rag.build_index
```

## Tech Stack

| Layer | Technology |
|---|---|
| Backend API | FastAPI + Uvicorn |
| Vector Search | FAISS (IndexFlatIP, cosine similarity) |
| Embeddings | `all-MiniLM-L6-v2` via sentence-transformers |
| LLM Inference | Ollama (local, CPU) |
| Frontend | Vanilla HTML / CSS / JavaScript |
